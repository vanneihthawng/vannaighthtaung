## Project Overview

This portfolio was developed as a professional platform for presenting my background in IT support and front-end development.

The website includes:

- Professional experience
- Technical training
- Education
- Certifications
- IT support skills
- Front-end development skills
- IT support labs and projects
- Front-end projects
- About section
- Contact information
- Contact form

The project was built with HTML5, CSS3, and Vanilla JavaScript without a front-end framework.
